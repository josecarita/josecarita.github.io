# josecarita.github.io

Source of my portfolio, [josecarita.github.io](https://josecarita.github.io), built with Jekyll and published with GitHub Pages.

- Projects are listed in `_data/projects.json` and each one has a page in `proj/`.
- Project images live in `static/projects/<project-id>/`.

Preview locally with `bundle install` and `bundle exec jekyll serve`.
